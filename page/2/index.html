MLA 把每个 token 的多头 Key、Value 压进一个共享的低维向量，再通过矩阵乘法的结合律，直接在压缩表示上计算注意力。这样可以显著缩小 KV Cache，也能减少生成阶段反复读取历史信息的开销。

Attention 流水线：单 Q 双 S 与双 Q 的计算重叠

发表于 2026-10-28 分类于 GPU 本文字数： 6.7k 阅读时长 ≈ 24 分钟

Attention 前向由两次矩阵乘和一段 softmax 交替组成。串行实现里，Tensor Core 算完 QK 要等 softmax，softmax 做完又要等 PV，两类运算单元轮流出空。把不同数据块上的工作交错排开，让一边等待时另一边继续算，是这个算子提高吞吐的主要来源。

在单个 CTA 内安排这种交错，有两种常见做法。单 Q 双 S 从同一个 query 块的相邻 KV 轮次里找重叠；双 Q 把两个 query 块放进同一个 CTA，让两条计算链交替推进。两者要回答的问题相同：哪些数据能提前算，哪些状态必须按顺序更新，多出来的中间结果放在哪里，为此占用的片上空间又是否划算。
